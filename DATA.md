# Data

This project uses the UCI Wine Recognition dataset distributed through scikit-learn.

- 178 samples
- 13 numerical chemical measurements
- known class labels are available, but they are not used to fit PCA or K-means

Source documentation: https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_wine.html

The experiment loads the data with `load_wine`. No local copy is required.
