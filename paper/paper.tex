\begin{abstract}
I use PCA and K-means to explore structure in the UCI Wine Recognition dataset without using the supplied class labels during fitting. A three-cluster solution gives the strongest tested silhouette score.
\end{abstract}

\section{Question}
Can a simple unsupervised pipeline reveal clear structure in real wine-chemistry measurements?

\section{Data and Method}
The dataset contains 178 samples and 13 numerical features. I standardize the features, reduce them to two principal components, and test K-means with $k$ from 2 through 6.

\section{Results}
PC1 explains 36.20\% of the variance and PC2 explains 19.21\%. The best tested solution is $k=3$ with a silhouette score of 0.5611.

\section{Limitations}
Clustering is performed in a two-dimensional PCA space, so information from the original feature space is discarded. K-means also favours compact Euclidean clusters.

\section{Reproduction}
Install \texttt{requirements.txt} and run \texttt{python src/run\_experiment.py}.
